# FSAE-Hornet-Racing-2026-Rear-Wing-Development
## Summary
Assisted in the carbon wet layup and CFD simulation of the rear wing, validating results against test lap data. Designed to improve the aerodynamic efficiency (Cl/Cd).
## Design Considerations
- First year to have a new aerodynamic kit since 2019 <br/>
- Budget is not large enough for prepreg or complex molding
## Results
Aerodynamic efficiency (Cl/Cd) from 1.75 to 1.96
